# Changelog

## 1.0.0

First release.

- A small red X in the top-right corner of each quest in the objective tracker. Click it to abandon the quest, with no popup.
- The same red X in the quest log, next to each quest's tracking checkbox.
- Shows only on quests the game lets you abandon.
- Optional Alt-click safety, a tooltip on the X and a chat message naming the abandoned quest and any quest items removed.
- `/questx` commands to switch each setting on or off.
